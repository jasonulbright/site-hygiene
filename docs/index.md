# Site Hygiene documentation

Site Hygiene scans a Configuration Manager site for clutter and drift, shows the live status of the site, and runs a fix only after you confirm it. A scan changes nothing. This page links every page of the documentation.

## Start

- [Getting started](getting-started.md): install, set the connection and run the first scan.

## Core

- [Findings](core/findings.md): the findings of a scan, the filters, Suppress, Run Fix and the exports.
- [Relationships](core/relationships.md): every supersedence and dependency relationship, as a list and as a tree.
- [Summary](core/summary.md): the count of each check and the notes about datasets that did not load.
- [Live views](core/live-views.md): Deployments, Content, Distribution Points, Client Health, Inactive Devices and Site Health.
- [Trends and alerts](core/trends-and-alerts.md): the history chart, the auto-refresh timer and the threshold alerts.
- [Options dialog](core/options.md): Connection, Scan, Live, Alerts and About.
