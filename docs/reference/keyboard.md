# Keyboard

This page lists the Tab order and the keys of Site Hygiene.

## What it does

Every control can be reached with the keyboard. A focus frame shows the control that has the focus.

## When to use it

Use it to work without a mouse.

## Requirements

None.

## Steps

### Tab order of the Findings view

Press Tab from the sidebar. The focus goes in this order:

1. The sidebar buttons: **Findings**, **Relationships**, **Summary**, **Deployments**, **Content**, **Distribution Points**, **Client Health**, **Inactive Devices**, **Site Health**, **Trends**, **Options**.
2. **Scan**.
3. The filter box.
4. The category list and the severity list.
5. **Export CSV** and **Export HTML**.
6. **Suppress**, **Unsuppress** and **Show Suppressed**. **Run Fix** is skipped while it is disabled.
7. The grid.

### Keys

| Key | Effect |
|---|---|
| Tab, Shift+Tab | Move the focus. |
| Enter, Space | Press the focused button. |
| Up, Down | Move in a grid, a list or a tree. |
| Esc | Close the Options dialog or a confirmation dialog, as **Cancel**. |

## Limits

- The Tab order of the other views follows the layout: the sidebar, the action bar, the filters and the grid.

## Troubleshooting

| Message or symptom | Cause | Fix |
|---|---|---|
| A button is skipped. | The button is disabled. | Select a row, or run a scan first. |
